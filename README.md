# Adewale Abdulrazaq Portfolio

Personal portfolio website showcasing my work as a Software Engineer with 5+ years of experience.

## Technologies Used

- HTML5 (Semantic Structure)
- CSS3 (Modern Animations, Grid/Flexbox)  
- JavaScript (ES6+)
- GSAP 3.7.1 (Animations)
- Lenis 1.3.15 (Smooth Scrolling)
- AOS (Animate On Scroll)

## Features

- ✨ Modern rotating goodbye circle animation
- 📱 Fully responsive design
- 🎨 Glass-morphism effects
- 🔄 Smooth scrolling with Lenis
- 📊 Dynamic project loading
- 🎯 Semantic HTML structure
- ♿ Accessibility optimized

## Development

```bash
npm install
npm run dev
```

## Deployment

This is a static website that can be deployed to any static hosting service like Vercel, Netlify, or GitHub Pages.

**Node.js 18+ is required for deployment.**
